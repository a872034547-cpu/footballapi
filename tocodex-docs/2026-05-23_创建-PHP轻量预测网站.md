# PHP 轻量预测网站 — 创建完成

日期：2026-05-23

## 概述

基于现有 FastAPI 足球情报服务（`d:/0523`，端口 8888），模仿 C:\0521 项目架构，创建了一个简单轻量的 PHP + SQLite 预测网站。

## 创建的文件

| 文件 | 说明 |
|------|------|
| `php-predict/config.php` | 配置文件（API 地址、DB 路径、预测参数） |
| `php-predict/functions.php` | 工具函数库（DB 单例、表初始化、API 调用、格式化） |
| `php-predict/style.css` | 深色主题样式（绿色强调、卡片布局、响应式） |
| `php-predict/sync.php` | CLI 脚本：同步比赛 + 生成预测 |
| `php-predict/settle.php` | CLI 脚本：结算已完成预测 |
| `php-predict/index.php` | 前端页面：ROI 仪表盘 + 今日预测 + 历史回溯 |
