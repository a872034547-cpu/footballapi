# 创建比赛详情页 detail.php

## 变更摘要
新建 `php-predict/detail.php`，实现比赛详情页，支持 URL 参数 `?match_id=xxx` 查看单场比赛的完整预测信息。

## 变更文件
- [`php-predict/detail.php`](php-predict/detail.php) — 新建，比赛详情页

## 功能要点
1. **URL 参数**：`?match_id=xxx`，缺失或无效时返回友好错误页
2. **数据源**：SQLite 本地数据 + FastAPI 实时数据双源
   - 未开赛：调用 `/match/{id}/analysis` 获取完整分析（含 pattern_matches）
   - 进行中：调用 `/match/{id}/rolling` 获取滚球预测
   - 已结束：仅展示本地缓存数据
3. **页面结构**：
   - 顶部导航 ← 返回首页
   - 比赛信息大卡片（联赛标签、主客队大号显示、比分、状态标签、开赛时间）
   - 综合分析区（信心等级、利好/风险因子、比分预测）
   - 三大市场预测详情卡片（胜平负/大小球/亚盘），含概率条 + 理由
   - 历史模式匹配证据（折叠面板，支持 4 种模式类型）
   - 滚球预测区（仅进行中比赛显示，AJAX 30s 轮询自动刷新）
4. **样式**：复用 style.css，内联补充详情页专属样式（大卡片、概率条、折叠面板、滚球卡片、因子标签等）
5. **安全**：所有输出使用 `e()` 转义，`declare(strict_types=1)`
