# 创建 PHP 项目兼容 API 层

## 背景
`C:\0521\FootballPredictSite` 是一个 PHP 7.4 + MySQL 足球预测网站，通过 `ExistingApiSource` 适配器调用外部 API。需要让 `d:/0523` 的 FastAPI 服务提供兼容端点，使 PHP 项目可以直接接入。

## PHP 项目 API 契约分析

| PHP 方法 | HTTP 调用 | 期望响应格式 |
|---|---|---|
| `getMatches()` | `GET /football/matches?type=all` | `{"code":200, "data":[{fid, home_team, ...}]}` |
| `getMatchInfo()` | `GET /analysis/info?fid={fid}` | `{"code":200, "data":{is_redis, odds_items, ...}}` |
| `analysisMatch()` | `POST /analysis/all` | `{"code":200, "data":{europe_win_all, ...}}` |
| `getDailyMatches()` | `GET /football/daily/{date}` | `{"code":200, "data":{data:[...]}}` |

关键逻辑：
- `analysisMatch()` 先调 `GET /analysis/info`，若 `is_redis=true` 且 `hasComputedAnalysisData()` 通过则直接返回
- 否则 fallback 到 `POST /analysis/all`
- `hasComputedAnalysisData()` 检查：`europe_win_all`, `asia_win_all`, `size_big_all` > 0，以及 `europe_score_list`, `infer_data`, `poisson_*` 非空
- `hasUsableAnalysisData()` 检查：`asia_odds_items`, `size_odds_items`, `europe_odds_items` 非空，`instant_pan_most`, `origin_pan_most` 有值

## 实现

### 新增文件
- [`app/routes/legacy_compat.py`](app/routes/legacy_compat.py) — 4 个兼容端点 + 字段映射 + 分析数据转换

### 修改文件
- [`app/main.py`](app/main.py) — 注册 `legacy_router`

### 字段映射
- `MatchRef.id` → `fid`
- `MatchRef.home_team.name` → `home_team`
- `MatchRef.away_team.name` → `away_team`
- `MatchRef.kickoff` → `match_time`
- `OddsPrice` 列表按 market 分组为 `europe_odds_items` / `asia_odds_items` / `size_odds_items`
- `AnalysisResponse` 映射为 `europe_win_all`, `asia_win_all`, `size_big_all`, `europe_score_list`, `infer_data`, `poisson_*` 等

### 验证结果
- 4 个端点全部 200，`code=200`
- `hasComputedAnalysisData` 检查：ALL PASS
- `hasUsableAnalysisData` 检查：ALL PASS
- 真实 wubai 比赛数据：`europe_win_all=56.31`, `asia_win_all=72.07`, `size_big_all=49.24`

## PHP 项目接入方式
修改 `C:\0521\FootballPredictSite` 的 `data_sources` 表或 `.env` 配置：
```
data_source.base_url = http://127.0.0.1:8888
```
或在 `data_sources` 表中插入：
```sql
INSERT INTO data_sources (name, type, base_url, enabled, priority)
VALUES ('local-fastapi', 'existing_api', 'http://127.0.0.1:8888', 1, 1);
