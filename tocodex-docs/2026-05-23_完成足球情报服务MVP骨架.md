# 足球情报服务 MVP 骨架交付备忘录

## 摘要

已完成一个可运行的 FastAPI 足球情报/赔率聚合与规则预测 MVP 骨架，包含：
- 统一配置与共享数据模型
- 健康检查、比赛查询、赔率查询、分析预测接口
- 多 provider 适配骨架（football-data、The Odds API、Goalserve）
- 聚合层与规则预测器
- Docker / Compose / Windows / Linux 一键部署文件
- `.env` 示例与 `README` 使用说明
