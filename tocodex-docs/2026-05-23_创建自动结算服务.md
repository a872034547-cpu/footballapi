# 2026-05-23 创建自动结算服务

## 变更摘要
创建 `app/services/settlement.py`，实现基于 APScheduler 的自动结算服务，并集成到 FastAPI 生命周期中。

## 变更文件
- [`app/services/settlement.py`](app/services/settlement.py) — **新建**，SettlementService 类 + 模块级调度器管理函数
- [`app/main.py`](app/main.py) — **修改**，添加 lifespan 上下文管理器，在 startup/shutdown 中启停调度器

## 核心实现
- **SettlementService**：管理预测结算逻辑，所有 sqlite3 操作通过 `run_in_executor` 在线程池中执行
- **结算方法**：`settle_1x2` / `settle_over_under` / `settle_asian_handicap`，逻辑与 `php-predict/settle.php` 一致
- **走水检测**：大小球 total==line、亚盘 score_diff==0 判定为 void
- **定时任务**：AsyncIOScheduler 每 60 秒执行 `check_and_settle`，misfire_grace_time=30s
- **数据库**：直接操作 `php-predict/data/predict.db`，读写 predictions / prediction_results / matches 表
