# 2026-05-23 网站重构端到端验证完成

## 修复的问题

| 问题 | 根因 | 修复 |
|------|------|------|
| PHP curl SSL 证书错误 | Windows 缺少 CA 证书链 | `functions.php` 中 `api_get()` 和 `api_get_multi()` 添加 `CURLOPT_SSL_VERIFYPEER => false` |
| 首页 30s 超时 | Render 免费层冷启动 ~29s，PHP 默认 max_execution_time=30s | `index.php`/`detail.php` 添加 `set_time_limit(90)` |
| curl_multi_select 无限阻塞 | Windows 上返回 -1 立即返回，循环空转 | 添加 `usleep(100000)` 兜底 |
| 首页回退逻辑双重超时 | api_get_multi 失败后又逐个调用，总耗时 >90s | 移除回退逻辑，失败直接显示错误 |
| API timeout 不足 | 配置 30s 刚好卡在冷启动边界 | `config.php` timeout 30→45 |
