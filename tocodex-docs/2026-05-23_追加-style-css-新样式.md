# 2026-05-23 追加 style.css 新样式

在 `php-predict/style.css` 末尾追加了以下新样式模块：

## 新增样式

1. **Tab 切换栏** (`.tab-bar` / `.tab-btn`) — 水平排列，激活态绿色底部边框，小屏幕横向滚动
2. **实时比分脉冲动画** (`@keyframes score-pulse` / `.score-updated`) — 0.6s ease-out 放大+绿色发光
3. **滚球预测卡片** (`.rolling-card`) — 概率条 `.prob-bar`、信心等级标签 `.confidence-a/b/c/d`、比赛分钟 `.live-minute` 红色脉冲圆点
4. **详情页布局** (`.detail-page`) — 返回按钮 `.back-link`、比赛大卡片 `.match-hero-card`、预测详情 `.prediction-detail-card`、折叠面板 `.accordion`、证据列表 `.evidence-list`
5. **刷新状态** (`.refresh-status` / `.spinning`) — 旋转动画
6. **加载状态** (`.loading-spinner`) — 旋转加载动画
