# 2026-05-23 修复详情页和赛程表关键 Bug

## 修复内容

### Bug 1: 详情页打不开
- **根因**: `index.php` 链接传 `detail.php?match_id=xxx`，但 `detail.php:16` 读 `$_GET['id']`
- **修复**: `detail.php:16` — `$_GET['id']` → `$_GET['match_id']`

### Bug 2: 赛程表渲染垃圾 JS 数据
- **根因**: zgzcw/nowscore provider 返回的原始 HTML/JS 代码（`var scheduleID = ...`、`CorrectPNG()` 等）未被过滤
- **修复**:
  - `functions.php` `e()`: 增加 `strip_tags()` + 超长字符串(>100字符)截断
  - `index.php` `team_name()`: 增加 `strip_tags()`
  - `index.php` `format_kickoff()`: `strtotime()` 失败时用正则提取 `HH:MM`，失败返回 `--:--`

### Bug 3: `mb_strlen()` 未定义
- **根因**: Windows PHP 默认不启用 `mbstring` 扩展
- **修复**: `mb_strlen` → `strlen`, `mb_substr` → `substr`

## 修改文件
- `php-predict/detail.php` — 参数名 `id` → `match_id`
- `php-predict/functions.php` — `e()` 增加 strip_tags + 长度截断 + mb_* → 原生函数
- `php-predict/index.php` — `team_name()` 增加 strip_tags, `format_kickoff()` 正则兜底
