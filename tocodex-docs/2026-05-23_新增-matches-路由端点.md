# 2026-05-23 新增 matches 路由端点

在 [`app/routes/matches.py`](app/routes/matches.py) 中追加了两个新端点。

## 变更内容

### 新增端点

1. **`GET /matches/live`** — 返回所有进行中比赛（LIVE/HT）的实时状态列表
   - 响应模型：`list[LiveMatchStatus]`
   - 从 `MatchRef.home_score/away_score/minute/live_status` 提取实时数据
   - 无实时数据时返回空列表，不报错

2. **`GET /matches/status?filter=live|finished|scheduled|all`** — 按状态筛选比赛
   - 响应模型：`list[MatchRef]`
   - 默认 `filter=all` 返回全部

### 新增辅助函数

- `_is_live()` — 判断 LIVE/HT
- `_is_finished()` — 判断 FT/FINISHED
- `_is_scheduled()` — 判断 SCHEDULED/NS
- `_match_to_live_status()` — MatchRef → LiveMatchStatus 转换

### 导入变更

- 新增 `Query` from fastapi
- 新增 `LiveMatchStatus` from app.models
